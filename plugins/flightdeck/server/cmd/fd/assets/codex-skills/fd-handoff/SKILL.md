# 마무리

**codex 판이다.** 이 창에는 flightdeck MCP 도구가 없다 — `fd` 터미널 명령이 전부다.
(Claude 창의 같은 이름 스킬은 `finish(...)` 도구 호출로 같은 일을 한다. 여기서는 같은 것을 `fd finish` 로 한다.)

명령은 `fd finish` 하나다. **판단 저장·후속 등록·종료·자원 반납이 한 트랜잭션**이라 지킬 순서가 없다 —
판단은 남았는데 항목이 열려 있거나, 항목은 닫혔는데 후속이 안 실린 상태로 끝날 수 없다.

## 한 번에 부른다

```
fd finish <집은 항목 id> \
  --outcome done \
  --title "<한 줄>" \
  --body - <<'EOF'
<아래 넷>
EOF
```

`--outcome dropped` 면 `--close-reason` 이 **필수**다.
`--body` 없이 부르면 **무엇을 적어야 하는지**를 그 자리에서 알려준다.
본문은 길다 — `--body -` 로 stdin 에서 받아라. 셸 인자로 넘기면 따옴표에서 깨진다.

## `--body` 의 넷

1. **왜 그렇게 했나**
2. **무엇을 기각했나**
3. **일부러 안 한 것** — 범위 밖으로 밀어낸 것 · 그대로 두는 게 옳아서 둔 것
4. **확인했지만 못 한 것** — 조사해서 "문제 없음"으로 돌아온 것도 여기다

git log 와 diff 가 이미 아는 것(무엇을 바꿨나)은 적지 마라.
여기 적을 것은 **다른 어디에도 안 남는 것** — 판단의 근거다.

## 후속은 트리아지가 먼저, 그리고 같은 호출에 싣는다

**본문이 곧 패치인 후속은 후속이 아니다 — 이 세션의 일이다.** 지금 하고 마무리를 미뤄라.

남겨야 하는 것만 `--followups` 로 **판단과 같은 트랜잭션에** 싣는다. 그래야 판단 링크가 붙어
다음 세션의 `fd pick` 이 그 항목과 함께 「왜 이게 생겼나」를 받는다.
나중에 `fd add` 로 따로 만들면 **그 연결은 영영 못 산다.**

```
cat > /tmp/followups.json <<'JSON'
[{"id": "…", "title": "…", "body": "…", "paths": ["…"], "labels": []}]
JSON

fd finish <집은 항목 id> --outcome done --title "<한 줄>" \
  --followups @/tmp/followups.json \
  --body - <<'EOF'
<위의 넷>
EOF
```

★ **`@<파일>` 로 줘라.** 후속 본문은 길고 줄바꿈·따옴표가 섞인다 — JSON 을 셸 인자로
직접 나르면 셸이 먼저 깨뜨리고, 깨진 JSON 은 (옳게도) 거절된다. 그 거절이 사람을
`fd add` 로 밀어내고, 그때 연결이 끊긴다. `--body -` 가 stdin 을 이미 쓰므로 이쪽은 파일이다.

**이미 있는 항목은 `id` 만 준다** — 새로 만들지 않고 판단에 **잇는다**.
(이 선점 뒤 내가 만든 열린 항목만이다.)

## 세션은 마지막에 닫는다

`fd finish <항목> --body - --close` 로 항목과 세션을 함께 닫는다. 항목 없이 닫으려면 `fd close`.
열어 둬도 보드 ①에는 안 앉는다(선점을 쥔 카드만 뜬다). 다만 겹침 판정은 창 내내 본다.
**선점이 남아 있으면 거절한다** — 닫힌 카드의 선점은 아무에게도 안 보인다.
되돌릴 수 있다: 다음 프롬프트나 도구 호출이 카드를 되살린다. 닫기는 관측이지 판정이 아니다.

## 가는 길에 남길 것

```
fd note --kind ask      --body -   # 남이 건드리면 안 되는 것. 커밋 전 의도를 나르는 유일한 통로
fd note --kind blocked  --body -   # 막혔다. 사유가 본문이다
fd note --kind decision --body -   # 되돌리기 비싼 결정과 그 근거
```

`--item <id>` 로 항목에 건다. `fd note` 는 **몇 세션이 받는지**를 보고한다 — 0이면 지금 아무도 안 본다.

## 랜딩

```
fd land                 # 줄에 선다(내 차례가 아니면 종료코드 1)
fd lane wait            # 차례까지 턴 안에서 기다린다
fd land --ok            # 다 쓰고 반납한다(랜딩됐다는 뜻이 아니다 — 레인을 놓았다는 뜻이다)
fd land --fail "사유"   # 검증이 깨져 반납한다
```
