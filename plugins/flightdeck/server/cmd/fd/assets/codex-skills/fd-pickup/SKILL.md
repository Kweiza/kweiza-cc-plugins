# Picking Up Work

**codex 판이다.** 이 창에는 flightdeck MCP 도구가 없다 — `fd` 터미널 명령이 전부다.
(Claude 창의 같은 이름 스킬은 `pick(...)` 같은 도구 호출을 가르친다. 여기서 그것을 부르면 아무것도 안 일어난다.)

## 1. 남부터 본다

```
fd status
```

**잡혀 있는 작업**(선점을 쥔 카드만) · 활동 배지 · 마지막 신호와 그 나이 · 경로 · 미확인이 나온다.
「죽음」 표시는 없다. 나이뿐이고, 판정은 사람이 한다.

## 2. 무엇을 집을지 고른다

```
fd next
```

**추천만 한다 — 선점하지 않는다.** 1순위 + **왜** · **각 구성원을 왜 묶었는지** · **탈락 사유 전부**.
묶을 것이 없으면 「단독」이라고 나온다 — 그 줄이 없으면 서버가 이 축을 안 낸 것이다.

## 3. 집는다

```
fd pick <선두> <나머지…>
```

**첫째가 선두다** — 그 id 가 브랜치·워크트리 이름이 된다. 나머지는 같은 워크트리에 함께 탄다.
선두가 실패하면 전부 거절되고, 선두가 되면 나머지는 갈 수 있는 데까지 가며 **못 간 것마다 사유**가 나온다.
하나만 집을 때도 같다: `fd pick <id>`.
선점은 본문 · **연결된 판단 전문** · 워크트리 명령을 돌려준다.

못 하겠으면 놓는다:

```
fd pick --leave "왜 못 하는지"          # 쥔 것 전부
fd pick <id> --leave "왜 못 하는지"     # 그 하나만
```

항목은 **`open` 으로 살아 돌아간다** — id·이력·`after` 가 그대로 산다.
**`fd finish --outcome dropped` 로 때우지 마라.** 그건 닫는 것이라 id 가 바뀌고 이력이 끊기며,
일 없이 닫힌 항목 하나가 큐 수지에 완료로 쌓인다.

★ `--leave` 는 **0.34.0 이상**에 있다. 낡은 설치본이면 그 플래그가 `fd pick --help` 에 안 보인다 —
그때는 놓지 말고 사람에게 말해라(dropped 로 때우는 것보다 낫다).

다시 집기를 요청하면 그것은 **맥락의 재출력**이지 거절이 아니다(맥락을 잃었을 때의 복귀 경로다).
`큐 열림 N건` 줄은 **그대로** 옮겨라 — 「이 응답에 없다」라고 적혀 있어도 그대로 옮기고,
아예 없으면(회수 거절·오프라인·낡은 fd) **수를 지어내지 마라.**

## 4. 계획 전에 연결된 판단을 읽어라

판단 절은 **본문의 대체물이 아니다** — 본문은 「무엇」이고 판단은 **「왜 그렇게 했나」**다:
무엇을 검토하고 왜 안 했는지, 어떤 증거가 거짓으로 드러났는지, **어디를 일부러 안 고쳤는지**.
건너뛰면 조사를 다시 하거나, **일부러 남긴 이음매를 결함으로 읽고 고치러 간다.**

## 5. 겹침이 오면 알린다

`fd pick` 은 **경로 겹침을 거르지 않고 알린다.** 겹치는 세션이 있으면 시작 전에 무엇을 만질지 선언해라:

```
fd note --kind ask --title "겹침 선언" --body "만질 경로: …"
```

본문이 길면 stdin 으로 준다: `fd note --kind ask --body - <<'EOF' … EOF`

## 이 스킬이 안 하는 것

세션 등록(훅이 한다 — `session` 인자는 없다) · 브랜치·HEAD·sha 기록(서버가 git 에서 읽는다) ·
잠금(없다) · 묶음 선택(서버가 정한다 — id 나열은 덮어쓰기용이다) · 남의 선점 회수(사람의 표면이다).
